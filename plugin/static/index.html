    主题要生效，需要把 neko-theme-studio.js/.css 与两行标签写进 N.E.K.O 自己的安装目录。安装目录不可写时（例如装在 Program Files、或 macOS 的 .app 里），脚本无法自动完成，见「为什么没生效？」。

    主题仓库

      仓库还是空的。调好配色后点「保存」，之后可以随时切回来，也可以「分享」成 zip 发给别人。

      「分享」导出的 zip 里带 theme.json 和用到的背景图片，别人用「导入包」就能一次拿走全套配色。
